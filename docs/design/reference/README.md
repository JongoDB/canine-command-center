# Design reference

[`k9-roadmap-artifact.html`](k9-roadmap-artifact.html) — the interface reference
supplied by the project owner (the **"K9 Training Roadmap — Command Curriculum"**
Claude artifact, extracted from a saved share page). Open it in a browser to see
it. It's a single self-contained HTML page (Google Fonts CDN for Bebas Neue / DM
Sans / Space Mono; no JS, no other dependencies).

It shows one screen — the program **timeline** for the default dog (Belgian
Malinois × Dutch Shepherd mix, female, high-drive) — but it defines the whole
app's visual language. The design system extracted from it (color/type tokens,
component kit, the four training tracks, screen-by-screen mapping, and the
protection-sport reconciliation) is written up in [`../../DESIGN.md`](../../DESIGN.md).
