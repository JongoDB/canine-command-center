# @ccc/web

Web client for Canine Command Center — Vite + React + React Router, installable
PWA. Shares domain logic with mobile via `@ccc/shared` and design tokens via
`@ccc/ui`. See [`../../docs/ARCHITECTURE.md`](../../docs/ARCHITECTURE.md) and
[`../../docs/DESIGN.md`](../../docs/DESIGN.md).

> **Status: scaffold only.** The real app (boot, auth screens, PWA, the
> Today/Program/Scout/Health/More screens) is built in milestone **M0.6** and
> the phases after it (see [`../../docs/ROADMAP.md`](../../docs/ROADMAP.md)).
