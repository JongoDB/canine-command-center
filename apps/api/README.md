# @ccc/api

Backend for Canine Command Center — Fastify + Postgres + Drizzle ORM (+ Better
Auth and the Claude/Scout SSE proxy in later milestones). The only component
that holds secrets or talks to Claude. See [`../../docs/ARCHITECTURE.md`](../../docs/ARCHITECTURE.md).

## Run it locally

```sh
cp .env.example .env          # then fill in real values (it's git-ignored)
pnpm db:up                    # Postgres (+ mailpit + minio) via Docker Compose
pnpm db:migrate               # apply Drizzle migrations
pnpm dev                      # Fastify on http://localhost:4000
curl http://localhost:4000/health        # { status: ok, db: ok, ... }
curl -i http://localhost:4000/health/ready
```

Other scripts: `pnpm build` (bundles to `dist/` with tsup) · `pnpm start` ·
`pnpm typecheck` · `pnpm test` (Vitest; runs without a DB — the DB sub-status is
just "down") · `pnpm db:generate` (new migration from schema changes) ·
`pnpm db:studio` (Drizzle Studio) · `pnpm db:down` / `pnpm db:logs`.

## Layout

```
src/
  config/env.ts     validated environment (zod); loads apps/api/.env via dotenv
  db/client.ts       Postgres pool + Drizzle client (lazy) + pingDb()
  db/schema.ts       Drizzle schema (Better Auth tables now; app tables from M1.1)
  db/migrate.ts       apply migrations & exit (used by db:migrate / db:check)
  routes/health.ts    GET /health (liveness), GET /health/ready (readiness)
  server.ts           buildServer() — Fastify app (cors, helmet, error envelope, routes)
  index.ts            entrypoint — buildServer().listen(), graceful shutdown
drizzle/              committed migrations + snapshots (generated by drizzle-kit)
drizzle.config.ts     drizzle-kit config
tsup.config.ts        prod bundle config
vitest.config.ts      test env (DATABASE_URL → unreachable on purpose)
```
