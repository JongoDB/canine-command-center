# @ccc/api

Backend for Canine Command Center — Fastify + Postgres + Drizzle ORM (+ Better
Auth and the Claude/Scout SSE proxy in later milestones). The only component
that holds secrets or talks to Claude. See [`../../docs/ARCHITECTURE.md`](../../docs/ARCHITECTURE.md).

## Run it locally

```sh
cp .env.example .env          # then fill in real values (it's git-ignored)
pnpm db:up                    # Postgres (+ mailpit + minio) via Docker Compose
pnpm db:migrate               # apply Drizzle migrations
pnpm dev                      # Fastify on http://localhost:4000
curl http://localhost:4000/health        # { status: ok, db: ok, ... }
curl -i http://localhost:4000/health/ready
```

Other scripts: `pnpm build` (bundles to `dist/` with tsup) · `pnpm start` ·
`pnpm typecheck` · `pnpm test` (Vitest; runs without a DB — the DB sub-status is
just "down") · `pnpm db:generate` (new migration from schema changes) ·
`pnpm db:studio` (Drizzle Studio) · `pnpm db:down` / `pnpm db:logs`.

Auth endpoints live under `/api/auth/*` (Better Auth — `sign-up/email`,
`sign-in/email`, `sign-out`, `verify-email`, `request-password-reset`, `reset-password`,
…). Authenticated routes (`/me`, `/dogs*`) need a valid session. Dogs:
`GET/POST /dogs`, `GET/PATCH/DELETE /dogs/:id`, `GET /dogs/:id/intake`,
`PUT /dogs/:id/intake`. Request bodies are validated against `@ccc/shared`'s Zod
schemas. In dev, verification / password-reset emails land in mailpit
(`pnpm db:up`, then http://localhost:8025).

## Layout

```
src/
  config/env.ts        validated environment (zod); loads apps/api/.env via dotenv
  db/client.ts          Postgres pool + Drizzle client (lazy) + pingDb()
  db/schema.ts          Drizzle schema (Better Auth tables + dog / intake_response)
  db/migrate.ts          applyMigrations() + the db:migrate/db:check script
  lib/email.ts           sendEmail() — SMTP (mailpit in dev) or log; captured in tests
  lib/validate.ts        parsed(schema, data) — Zod → 400 VALIDATION envelope
  auth/auth.ts           Better Auth instance (email/password + verify + reset)
  auth/plugin.ts         mounts Better Auth at /api/auth/* (Fastify ↔ Fetch bridge)
  auth/requireSession.ts preHandler — 401s without a session, else sets request.auth
  routes/health.ts       GET /health (liveness), GET /health/ready (readiness)
  routes/me.ts           GET /me (protected) — the current user
  routes/dogs.ts         /dogs* — dog CRUD + intake (versioned), owner-scoped
  server.ts              buildServer() — Fastify app (cors, helmet, error envelope, routes)
  index.ts               entrypoint — buildServer().listen(), graceful shutdown
  test-helpers.ts        createTestUser(app) — for DB-backed integration tests
drizzle/                committed migrations + snapshots (generated by drizzle-kit)
drizzle.config.ts / tsup.config.ts / vitest.config.ts / vitest.setup.ts
```

Tests run without a DB by default (db-backed suites self-skip). To run them all:
`pnpm db:up && DATABASE_URL=postgres://ccc:ccc_dev_password@localhost:5432/ccc pnpm --filter @ccc/api test`.
